# Adaptive Task Planning

## Error:

A fixed task plan can become difficult to follow when the user's available time changes or when tasks are delayed. Large tasks can also feel difficult to start when they are presented as one activity without smaller steps.

## Relevant Context

The purpose of FOCUS.OS is to support flexible task planning. The recommendation workflow considers deadlines, priorities, estimated duration and available time. The application also supports breaking larger tasks into smaller subtasks.

## Key Observation

A useful plan should respond to changing circumstances. In addition, dividing a large task into smaller steps can make the work easier to understand and approach.

## Solution

Adaptive scheduling was incorporated so that recommendations could be reconsidered when task details or available time changed. Task breakdown was also included to help users organise larger activities into smaller, more manageable steps.
