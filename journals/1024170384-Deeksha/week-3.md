# What Should I Do Now?

## Error:

When users have multiple pending tasks, deciding which one to begin can itself require time and effort. A list ordered only by creation date or manually assigned priority may not suggest the most practical task for the user's current situation.

## Relevant Context

FOCUS.OS includes a feature called "What Should I Do Now?" to help users select their next task. The recommendation process considers task information such as priority, deadline and estimated duration, along with the amount of time the user has available.

The application also provides an explanation for the recommendation.

## Key Observation

The most important task is not always the most suitable task to perform immediately. For example, a shorter task may be more practical when the user has limited time, while an approaching deadline may make another task more urgent.

## Solution

The recommendation feature was developed to consider multiple task attributes instead of relying on a single fixed ordering. It presents a suggested task and gives the user a reason for the suggestion, while keeping the user in control of the final decision.
