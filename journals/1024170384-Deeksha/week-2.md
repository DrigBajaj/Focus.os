# Task Management

## Error:

A simple task list can become difficult to manage when users have several activities with different deadlines, priorities and time requirements. Recording tasks alone does not provide enough information to organise them effectively.

## Relevant Context

Task management is one of the main features of FOCUS.OS. Users need to be able to record their tasks and provide details that help the application understand the work involved.

The task workflow includes information such as task title, deadline, priority and estimated duration.

## Key Observation

Tasks require more than a title to be useful for planning. Deadlines indicate urgency, priority communicates importance, and estimated duration helps determine whether a task fits into the time available.

## Solution

The task-management experience was developed around these details so that users could create and organise tasks with the information needed by the recommendation system. This also established a common basis for connecting task management with the rest of the application.
