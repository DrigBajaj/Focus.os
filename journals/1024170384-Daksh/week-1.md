# Focus and Engagement Design

## Error:

A productivity application can help users organise tasks, but users also need a comfortable way to spend time working on those tasks. Without a dedicated focus experience, task planning and actual task execution can feel disconnected.

## Relevant Context

FOCUS.OS was designed to bring task planning and focus support together. Alongside the main task list, the application includes a dedicated focus area and engagement features intended to make progress visible.

## Key Observation

The transition from choosing a task to actually working on it should be simple. The focus experience should support the user's selected task without introducing unnecessary distractions.

## Solution

The focus and engagement experience was planned around a dedicated Focus Screen, with supporting progress and companion features. This allowed the application to connect task selection with focused work and visible progress.
